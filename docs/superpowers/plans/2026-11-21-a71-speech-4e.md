# A71 Speech Follow-up (Plan 4E) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix what the A71 run of plan 4D found in speech: Kestrel's own phrases after its name accept one misheard word, the A71's corpus check judges each line as `voice-eval` does and compares the air with the same lines fed in directly in the same run, the keyword spotter's rule needs enough data before it moves away from its default, and barge-in over the loudspeaker is measured on the A71 and then fixed from the numbers.

**Architecture:** Task 1 changes Kotlin in `:core:voice` and `:app`: the endpointer also notes the spotter's "stop" at the start of an utterance, and `Requests` accepts "wake up" with one wrong word and "Stop Kestrel" with a farther name when the spotter heard "stop"; a near miss of "wake up" starts no task while Kestrel is paused. Task 2 moves `voice-eval`'s verdict of a corpus line into `CorpusVerdict`, which `voice-expect` now uses too, with the line's group, its scene's labels and the contacts. Task 3 makes the step `corpus` of `scripts\a71-commands.ps1` feed each owner line directly on the phone, play it through the air, compare the two with Wilson intervals, give the one-word lines apart and record the lines that only the air lost; it fixes the corpus (c104, Piper's c163) and the spec's targets. Task 4 changes the spotter's rule and adds the step `barge-in` to `scripts\a71-session.ps1`, which measures Kestrel's echo against the owner's "Kestrel" on the A71 and prints a decision by a rule fixed in advance (`Get-BargeInDecision`). Task 5 follows that decision: Kestrel lowers its own voice on the loudspeaker by the measured amount, or nothing changes, and a device test feeds a mix of a reply and "Kestrel" into the pipeline. Task 6 runs the A71 again without the owner and writes the results into spec 19.1 and the README.

**Tech Stack:** Kotlin 2.4.21, kotlinx.coroutines 1.11.0, JUnit 4, AndroidX Test, the Android SDK's `AudioManager` and `AudioDeviceInfo`, PowerShell 7.3 for `scripts\hook.ps1`, `scripts\a71-commands.ps1` and `scripts\a71-session.ps1`, Pester 6.2.0 and PSScriptAnalyzer 1.25.0 for the scripts.

## Changes to the design that this plan makes

- Spec 8.3: after the name, "wake up" counts with one word misheard, missing or extra; a near miss two words away starts no task while Kestrel is paused; "Stop Kestrel" counts with a first word one letter away from "stop" and a name three letters away when the spotter heard "stop" at the start.
- Spec 5.3, 8.3, 16.4 and 18.3: on the A71, the corpus step measures the owner lines fed in directly and through the air in the same run; through the air, each voice's share of the lines of two or more words must be at most 5 points below its share fed in directly, each share with its Wilson interval; the one-word lines are reported apart. The 95 % (Kokoro) and 88 % (Piper) targets stay for the emulator's direct measure.
- Spec 8.4: barge-in over the loudspeaker, as Task 5's branch decides.
- The spotter's rule of the A71 session moves away from the default only after at least 20 tries per setting of each of "Kestrel", "Hey Kestrel" and "Kestrel, wake up", and at least 10 minutes of speech without a keyword, with the false hits counted by keyword.

inv-a71-speech, section 3, found that the spotter heard the name in both failed tries of "Kestrel, wake up" while paused, but the recogniser got one word wrong, so `Requests` read a task and Kestrel started one; and that the failed "Stop Kestrel" had the spotter's "stop" but no hit of the name, so the name was allowed only 2 letters. The owner's decision 4 (2026-11-21): after the name, "wake up" counts with at most one wrong word, "Stop Kestrel" counts when the spotter heard "stop" at its start, and a near miss of "wake up" while Kestrel is paused never starts a task.

A word of "wake up" counts as misheard when at most half of its letters differ from the word that it replaces ("make", "woke" or "wait" for "wake", "op" for "up"); a missing or an extra word counts one too, so "Kestrel, wake" and "Kestrel, wake me up" wake Kestrel up. Any other word counts as one missing and one extra, so "Kestrel, sign up" is two words away: a near miss, which is a task while Kestrel listens and nothing while it is paused. "Kestrel, call Mom", four words away, stays a task, and "No." in an answer to "Yes?" stays a task, because "no" is two letters away from "up". The endpointer marks an utterance whose first 1.5 s held the spotter's "stop", as it marks the name, and `Requests` then lets the first word be one letter away from "stop" and the name three letters away, as after the spotter's "Kestrel". A false "stop" of the spotter cannot turn Kestrel off without a word like "stop" and a word like the name.

/**
 * Whether what Kestrel heard leads to the action that a corpus line's text leads to (design spec, section 16.4), for the
 * hooks voice-eval and voice-expect, so that the A71's lines through the air count as the emulator's do (plan 4E): 1 or

internal object CorpusVerdict {
    /** The groups of corpus\commands.txt whose lines are instant commands, speech that must stay bare, and dictation. */
    const val APPENDIX = "appendix"
    const val CONVERSATION = "conversation"
    const val DICTATION = "dictation"

        val right = when (group) {

                wanted != null && said != null && Commands.sameAction(wanted, said, labels, contacts)
            }
            else -> return "-"
        }
        return if (right) "1" else "0"
    }

import android.os.Build
import android.os.SystemClock
import dev.kestrel.app.AppGraph
import dev.kestrel.app.debug.TestHooks.HookError
import dev.kestrel.app.listen.BoostWordBudget
import dev.kestrel.app.orchestrator.Event
import dev.kestrel.commands.Command
import dev.kestrel.commands.CommandParser
import dev.kestrel.commands.Commands

/**
 * Hook H2 of plan 4D, voice-expect: the phone compares the next transcripts of Kestrel's voice session with the text of a
 * clip that the PC plays, so that an air check reads the result of its own clip and never of a stray utterance
 * (2026-11-20-a71-checks-4d-interfaces.md, section 4). The match runs with its tag, as a tagged `voice -Send heard` does, or with `noRun`
 * is only resolved; every other transcript while the expectation holds is dropped. With a corpus line's group (`group`),
 * its scene's labels (`labels`) and the corpus's contacts (`contacts`), a match with `noRun` is judged as voice-eval
 * judges the line, with CorpusVerdict (plan 4E). The answers hold counts, times on the phone's clock and kinds, never what
 * Kestrel heard.
 */
internal class ExpectHooks(private val graph: AppGraph) {
    fun run(command: String, intent: Intent): String = when (command) {
        "VOICE_EXPECT" -> if (intent.getBooleanExtra(EXTRA_RESULT, false)) result(tag(intent)) else expect(intent)
        else -> throw HookError("unknown command '$command'")
    }

    private fun tag(intent: Intent): String = intent.getStringExtra(EXTRA_TAG) ?: throw HookError("add --es tag <tag>")

    private fun expect(intent: Intent): String {
        val tag = tag(intent)
        if (!TAG.matches(tag)) throw HookError("add --es tag with 1 to 32 letters, digits, '-' and '_'")
        val text = intent.getStringExtra(EXTRA_TEXT) ?: throw HookError("add -Text with words")
        val seconds = intent.getIntExtra(EXTRA_SECONDS, DEFAULT_SECONDS)
        if (seconds !in 1..MAX_SECONDS) throw HookError("add --ei seconds with 1 to $MAX_SECONDS")
        val noRun = intent.getBooleanExtra(EXTRA_NO_RUN, false)
        if (!noRun && VoiceHooks.refused(text, Build.HARDWARE)) throw HookError(VoiceHooks.YES_CALL_REFUSED)
        // As voice-eval reads them: without contacts, the labels are the contacts too.
        val corpus = intent.getStringExtra(EXTRA_GROUP)?.let { group ->
            val labels = names(intent.getStringExtra(EXTRA_LABELS))
            CorpusLine(group, labels, intent.getStringExtra(EXTRA_CONTACTS)?.let { names(it) } ?: labels)
        }
        val listening = graph.listening
        if (!listening.sessionOpen.value) throw HookError("Kestrel's voice session is not open")
        val now = SystemClock.elapsedRealtime()
        synchronized(lock) {
            val current = expectation
            if (current != null && current.waiting(now)) {
                throw HookError("an expectation waits; ask for its answer with -Result -Tag ${current.tag}")
            }
            if (current?.tag == tag || VoiceHooks.tags.tagged(tag) != null) {
                throw HookError("the tag $tag is in use; give each transcript a new tag")
            }
            val next = Expectation(tag, text, noRun, now + seconds * 1_000L)
            if (next.words == 0) throw HookError("add -Text with words")
            expectation = next
            line = corpus
            listening.transcripts = { event -> check(graph, event) }
        }
        return "expecting tag=$tag seconds=$seconds"
    }

    private fun result(tag: String): String {
        val now = SystemClock.elapsedRealtime()
        synchronized(lock) {
            val current = expectation?.takeIf { it.tag == tag } ?: throw HookError("no expectation has the tag $tag")
            if (current.waiting(now)) return "waiting tag=$tag"
            val match = current.match
            val run = !current.noRun
            val number = if (run) VoiceHooks.tags.tagged(tag)?.command ?: 0 else 0
            val (kind, outcome) = if (run) VoiceHooks.kindAndOutcome(graph, number) else (match?.kind ?: "none") to "none"
            val corpus = line
            val right = when {
                run -> "-"
                match != null -> match.right
                // As voice-eval answers for a clip in which the recogniser heard nothing (plan 4E).
                corpus != null -> CorpusVerdict.command(corpus.group, current.expected, "", corpus.labels, corpus.contacts)
                isCommand(current.expected) -> "0"
                else -> "-"
            }
            return "tag=$tag matched=${match != null} words=${current.words} errors=${current.errors} stray=${current.stray} " +
                "split=${current.split} speechEnded=${match?.speechEnded ?: 0} closed=${match?.closed ?: 0} " +
                "transcribed=${match?.transcribed ?: 0} run=$run command=$number kind=$kind outcome=$outcome right=$right"
        }
    }

    companion object {
        val COMMANDS = setOf("VOICE_EXPECT")

        private val lock = Any()

        // The newest expectation; its answer stays until the next one.
        private var expectation: Expectation? = null

        // The corpus line of the newest expectation, or null when voice-expect named no group (plan 4E).
        private var line: CorpusLine? = null

        private val TAG = Regex("[A-Za-z0-9_-]{1,32}")
        private const val DEFAULT_SECONDS = 15
        private const val MAX_SECONDS = 60
        private const val EXTRA_TEXT = "text"
        private const val EXTRA_TAG = "tag"
        private const val EXTRA_SECONDS = "seconds"
        private const val EXTRA_RESULT = "result"
        private const val EXTRA_NO_RUN = "noRun"
        private const val EXTRA_GROUP = "group"
        private const val EXTRA_LABELS = "labels"
        private const val EXTRA_CONTACTS = "contacts"

        // Decides for each transcript of a voice session whether it goes on to the Orchestrator, on the session's thread.
        private fun check(graph: AppGraph, event: Event.Heard): Boolean {
            val now = SystemClock.elapsedRealtime()
            synchronized(lock) {
                val current = expectation ?: return true
                if (!current.holds(now)) return true
                val noRun = current.noRun
                val corpus = line
                val verdict: (String) -> Pair<String, String> =
                    { heard -> if (noRun) resolve(graph, current.expected, heard, corpus) else "none" to "-" }
                if (!current.offer(event.text, event.endedAt, event.closedAt, now, verdict)) return false
                if (noRun) return false
                try {
                    VoiceHooks.tag(graph, current.tag, event)
                } catch (e: HookError) {
                    // A tagged text with the same tag came meanwhile; the match runs untagged, and its answer says command=0.
                }
                // Process rule 10: a heard "yes, call" never reaches Kestrel through a hook on a phone, also as a match. Its tag
                // stays, with no command, so that voice-state -Tag answers role=none.
                if (VoiceHooks.refused(event.text, Build.HARDWARE)) {
                    VoiceHooks.tags.dropped(event)
                    return false
                }
                return true
            }
        }

        // The kind of command that [heard] parses to, and 1 when it leads to the same action as [expected] with the screen's
        // labels, 0 when not, - when [expected] is no instant command, as voice-eval's command= (design spec, section 16.4).
        // A corpus line is judged as voice-eval judges it, with its own group, labels and contacts (plan 4E).
        private fun resolve(graph: AppGraph, expected: String, heard: String, corpus: CorpusLine?): Pair<String, String> {
            val said = CommandParser.parse(heard)
            val kind = said?.javaClass?.simpleName ?: "none"
            if (corpus != null) return kind to CorpusVerdict.command(corpus.group, expected, heard, corpus.labels, corpus.contacts)
            val wanted = CommandParser.parse(expected)
            if (wanted == null || wanted is Command.Bare) return kind to "-"
            val labels = graph.screen.value?.snapshots?.latest()?.snapshot?.let { BoostWordBudget.screenNames(it) }.orEmpty()
            return kind to if (said != null && Commands.sameAction(wanted, said, labels)) "1" else "0"
        }

        private fun isCommand(text: String): Boolean = CommandParser.parse(text).let { it != null && it !is Command.Bare }

        // The names of an extra separated by ';', as voice-eval reads its labels and contacts.
        private fun names(text: String?): List<String> = text?.split(';')?.map { it.trim() }?.filter { it.isNotEmpty() }.orEmpty()
    }

    /** A corpus line's group, the labels of its scene and the contacts, with which voice-expect judges a match (plan 4E). */
    private class CorpusLine(val group: String, val labels: List<String>, val contacts: List<String>)
}

    if ($Contacts.Count -gt 0) { $options.Contacts = $Contacts -join ';' }

# The Wilson score interval at 95 % (z = 1.96) of $Right out of $Total, in percent with one decimal (Low and High), or
# $null for both without any line.
function Get-WilsonInterval([int]$Right, [int]$Total) {
    if ($Total -le 0) { return [pscustomobject]@{ Low = $null; High = $null } }
    $z = 1.96
    $share = $Right / $Total
    $spread = $z * $z / $Total
    $centre = ($share + $spread / 2) / (1 + $spread)
    $half = $z * [math]::Sqrt($share * (1 - $share) / $Total + $spread / (4 * $Total)) / (1 + $spread)
    [pscustomobject]@{
        Low = [math]::Round(100 * [math]::Max([double]0, $centre - $half), 1, [MidpointRounding]::AwayFromZero)
        High = [math]::Round(100 * [math]::Min([double]1, $centre + $half), 1, [MidpointRounding]::AwayFromZero)
    }
}

# A share with its Wilson interval, such as '70 of 72 (97.2 %, 90.4 to 99.2 %)', or '0 of 0'.
function Format-Share([int]$Right, [int]$Total) {
    if ($Total -le 0) { return '0 of 0' }
    $interval = Get-WilsonInterval -Right $Right -Total $Total
    $invariant = [Globalization.CultureInfo]::InvariantCulture
    "$Right of $Total ($(Format-Percent $Right $Total) %, $($interval.Low.ToString('0.0', $invariant)) to $($interval.High.ToString('0.0', $invariant)) %)"
}

# New totals of the commands of one pass of the A71's corpus step (plan 4E): the lines of two or more words (Right of
# Total) and the one-word lines apart (OneRight of OneTotal), and each line's verdict by its id (Verdicts).
function New-CommandTotals {
    [pscustomobject]@{ Right = 0; Total = 0; OneRight = 0; OneTotal = 0; Verdicts = @{} }
}

# Adds the verdict of the line $Id, whose text is $Text, to the totals: '1' or '0', as voice-eval's command= and
# voice-expect's right= answer; '-', a line without a command to judge, does not count.
function Add-CommandVerdict($Totals, [string]$Id, [string]$Text, [string]$Right) {
    if ($Right -notin '0', '1') { return }
    $Totals.Verdicts[$Id] = $Right
    if (@($Text -split '\s+' | Where-Object { $_ }).Count -eq 1) {
        $Totals.OneTotal++
        if ($Right -eq '1') { $Totals.OneRight++ }
    } else {
        $Totals.Total++
        if ($Right -eq '1') { $Totals.Right++ }
    }
}

# The results' line that compares one voice's commands through the air with the same lines fed in directly in the same
# run (design spec, section 5.3; plan 4E): the lines of two or more words meet the target when the air's share is at most
# 5 points below the direct share; the one-word lines are given apart, so that they do not decide alone; and the ids of
# the lines that were right directly and wrong through the air. Each share comes with its Wilson interval at 95 %.
function Format-CommandComparison([string]$Voice, $Direct, $Air) {
    $invariant = [Globalization.CultureInfo]::InvariantCulture
    $verdict = 'not compared, because a pass has no line of two or more words'
    if ($Direct.Total -gt 0 -and $Air.Total -gt 0) {
        $points = [math]::Round(100.0 * $Direct.Right / $Direct.Total - 100.0 * $Air.Right / $Air.Total, 1, [MidpointRounding]::AwayFromZero)
        $gap = if ($points -ge 0) { "$($points.ToString('0.0', $invariant)) points below" } else { "$((-$points).ToString('0.0', $invariant)) points above" }
        $verdict = "the air's share is $gap the direct share: target $(if ($points -le 5) { 'met' } else { 'missed' }) (at most 5 points below)"
    }
    $lost = @($Direct.Verdicts.Keys | Where-Object { $Direct.Verdicts[$_] -eq '1' -and $Air.Verdicts[$_] -eq '0' } | Sort-Object)
    "${Voice}: commands right in the lines of two or more words: directly $(Format-Share $Direct.Right $Direct.Total), " +
    "through the air $(Format-Share $Air.Right $Air.Total); $verdict; one-word lines: directly " +
    "$(Format-Share $Direct.OneRight $Direct.OneTotal), through the air $(Format-Share $Air.OneRight $Air.OneTotal); " +
    "right directly and wrong through the air: $(if ($lost.Count -gt 0) { $lost -join ', ' } else { 'none' })"
}

function Select-SpotterWinner([object[]]$Rounds) {

    if (-not $default) { return [pscustomobject]@{ Setting = $null; Reason = 'no setting chosen, because the default setting was not measured whole' } }

    $minutes = ($Rounds | ForEach-Object { [double]$_.Minutes } | Measure-Object -Minimum).Minimum

                "$([math]::Round($minutes, 1)) minutes"
        }
    }

            $round = $_
            @($keywords | Where-Object { (Get-TableCount $round.FalseHits $_) -gt 2 * (Get-TableCount $default.FalseHits $_) + 2 }).Count -eq 0
        })

    $falseHits = { $round = $_; ($keywords | ForEach-Object { Get-TableCount $round.FalseHits $_ } | Measure-Object -Sum).Sum }

# The number under $Key in the table $Table, or 0 when the table or the key is missing.
function Get-TableCount($Table, [string]$Key) {
    if ($Table -and $Table.Contains($Key)) { [int]$Table[$Key] } else { 0 }
}

# The decision of plan 4E's fix of barge-in, which its Task 5 follows, from the rows of the A71 session's step barge-in:
# each has Volume and Max (the media volume's step and its top), ClipDb (the level at which the phone heard this
# computer's "Kestrel", the loudest 20 ms frame), EchoDb (the median level of Kestrel's own reply at the microphone, the
# same measure), Tries and Interrupted. A row succeeded when at least 3 of 4 of its tries interrupted Kestrel, and its
# margin is ClipDb minus EchoDb. The normal row is the one at the top volume with the quietest "Kestrel", as the owner
# speaks in a quiet room. The rule, written down before the measure:
# - no row with a level and a try: 'unmeasured';
# - the normal row succeeded: 'none', and nothing changes;
# - otherwise the margin that is needed is the smallest margin of a row that succeeded while the rows with that margin
#   or more succeeded in at least 3 of 4 of their tries together; without one, 'blocked': no level of the echo made the
#   interruption work, so its cause is not the echo;
# - the reduction R is the needed margin minus the normal row's margin, in whole dB, rounded up, at least 1: 'volume' when
#   R is at most 15 dB, so that Kestrel speaks R dB quieter on the phone's own loudspeaker, and 'limit' when it is more,
#   because the replies would then be too quiet to hear in a room.
# Returns Branch, ReductionDb, NameDb (the normal row's "Kestrel"), EchoDb (the normal row's echo), WorkingEchoDb (the echo
# below which the A71 was interrupted at the normal "Kestrel": NameDb minus the needed margin, or EchoDb for 'none') and
# MarginDb; the levels are in dBFS with one decimal.
function Get-BargeInDecision([object[]]$Rows) {
    $measured = @($Rows | Where-Object { $_.Tries -gt 0 -and $null -ne $_.ClipDb -and $null -ne $_.EchoDb })
    $none = [pscustomobject]@{ Branch = 'unmeasured'; ReductionDb = 0; NameDb = $null; EchoDb = $null; WorkingEchoDb = $null; MarginDb = $null }
    if ($measured.Count -eq 0) { return $none }
    $top = ($measured | Measure-Object -Property Volume -Maximum).Maximum
    $normal = @($measured | Where-Object { $_.Volume -eq $top } | Sort-Object ClipDb)[0]
    $round = { param($Value) [math]::Round([double]$Value, 1, [MidpointRounding]::AwayFromZero) }
    $decision = [pscustomobject]@{
        Branch = 'none'; ReductionDb = 0; NameDb = & $round $normal.ClipDb; EchoDb = & $round $normal.EchoDb
        WorkingEchoDb = & $round $normal.EchoDb; MarginDb = & $round ($normal.ClipDb - $normal.EchoDb)
    }
    if (4 * $normal.Interrupted -ge 3 * $normal.Tries) { return $decision }
    $needed = $null
    $triesAbove = 0
    $interruptedAbove = 0
    foreach ($row in @($measured | Sort-Object { $_.ClipDb - $_.EchoDb } -Descending)) {
        $triesAbove += $row.Tries
        $interruptedAbove += $row.Interrupted
        # One unlucky row of 4 tries neither ends the walk nor hides a row that worked below it.
        if (4 * $row.Interrupted -ge 3 * $row.Tries -and 4 * $interruptedAbove -ge 3 * $triesAbove) { $needed = $row.ClipDb - $row.EchoDb }
    }
    if ($null -eq $needed) {
        $decision.Branch = 'blocked'
        return $decision
    }
    $reduction = [int][math]::Max(1, [math]::Ceiling($needed - ($normal.ClipDb - $normal.EchoDb)))
    $decision.Branch = if ($reduction -le 15) { 'volume' } else { 'limit' }
    $decision.ReductionDb = $reduction
    $decision.WorkingEchoDb = & $round ($normal.ClipDb - $needed)
    $decision.MarginDb = & $round $needed
    $decision
}

# what the counts of voice-counts rose by.
function Measure-BargeInTry([double]$Gain) {
    Wait-Quiet
    $counts = Get-Counts
    Invoke-CorpusClip k022 kokoro
    if ((Wait-State { param($State) $State.speaking -eq 'true' } 30) -lt 0) {
        return [pscustomobject]@{ EchoDb = $null; Interrupted = $false; Rise = Get-CountRise $counts (Get-Counts) }
    }
    Invoke-Hook voice-route | Out-Null
    Start-Sleep -Seconds 3
    $level = (ConvertFrom-HookPairs (Invoke-Hook voice-route))['frameRms']
    $echo = if ($level -match '^-?\d+(\.\d+)?$') { [double]::Parse($level, [Globalization.CultureInfo]::InvariantCulture) } else { $null }
    if ($DryRun) { Invoke-CorpusClip c041 kokoro } else { Invoke-Clip -Path (Join-Path $generatedRoot 'kokoro\c041.wav') -Gain $Gain | Out-Null }
    $stopped = (Wait-State { param($State) $State.speaking -eq 'false' -and $State.work -eq 'awaiting_task' } 5) -ge 0
    [pscustomobject]@{ EchoDb = $echo; Interrupted = $stopped; Rise = Get-CountRise $counts (Get-Counts) }
}

# What came after Kestrel's own reply when nobody interrupted it (inv-a71-speech, section 3, "A side issue"): k022 makes
# Kestrel read the long reply of voice-task to its end, no clip plays meanwhile, and the 5 s after it show which commands
# started (voice-state -Number: kind and outcome), how long after the end of the latest transcribed speech Kestrel's
# latest reaction came, and what the pipeline heard (voice-counts). Returns whether a command started.
function Measure-ReplyTail([int]$Try) {
    Wait-Quiet
    Invoke-CorpusClip k022 kokoro
    if ((Wait-State { param($State) $State.speaking -eq 'true' } 30) -lt 0) {
        Add-Result barge-in "the reply's end, try ${Try}: Kestrel did not begin its reply within 30 s"
        return $false
    }
    $counts = Get-Counts
    $since = [long](Get-Times)['now']
    $before = [int](Get-VoiceState).command
    $ended = Wait-State { param($State) $State.speaking -eq 'false' } 90
    Start-Sleep -Seconds 5
    $latest = [int](Get-VoiceState).command
    $commands = @(for ($number = $before + 1; $number -le $latest; $number++) {
            $state = ConvertFrom-VoiceState (Invoke-Hook voice-state @{ Number = $number })
            "$($state.kind) ($($state.outcome))"
        })
    $reaction = Get-Reaction $since 'command'
    Add-Result barge-in ("the reply's end, try ${Try}: the reply $(if ($ended -ge 0) { 'ended' } else { 'did not end within 90 s' }); " +
        "$($commands.Count) commands started after it$(if ($commands.Count -gt 0) { ': ' + ($commands -join ', ') }); Kestrel's latest " +
        "command: $(if ($reaction) { $reaction } else { 'none' }); counts: $(Get-CountRise $counts (Get-Counts))")
    $commands.Count -gt 0
}

# The step barge-in (plan 4E; the owner's decision 6): see the script's header. A failed try costs only its own line.
function Invoke-BargeInStep {
    if (-not (Initialize-Air barge-in)) { return }
    # The A71 run of plan 4D may have left another setting in Kestrel's process; it counts from the next start.
    Add-Result barge-in "the keyword spotter's setting: $(Invoke-Hook voice-spotter @{ Boost = 2; Threshold = 0.15 })"
    $volume = Get-MediaVolume
    $volumeRestore = Register-Restore 'the media volume' "Run: & '$adb' -s $Serial shell cmd media_session volume --stream 3 --set $($volume.Index)" $volume.Index {
        param($Data)
        Assert-TestDevice -Serial $Serial
        Invoke-Checked "cmd media_session volume --stream 3 --set $Data" | Out-Null
    }
    $story = 'Here is a long reply, so that you can interrupt it. ' + ('The news of the day comes one sentence after another, at an even pace. ' * 6)
    Invoke-Hook voice-task @{ Seconds = 1; Reply = $story } | Out-Null
    $rows = [System.Collections.Generic.List[object]]::new()
    $tries = if ($DryRun) { 1 } else { 4 }
    try {
        $levels = [System.Collections.Generic.List[object]]::new()
        Stop-Kestrel
        try {
            foreach ($target in -24, -18, -12) {
                if ($DryRun) {
                    $levels.Add([pscustomobject]@{ Target = $target; Gain = 1.0; LevelDb = $null })
                    continue
                }
                $level = Set-SpeakerLevel -TargetDb $target -Measure { param($Gain) Measure-NameLevel $Gain }
                $levels.Add([pscustomobject]@{ Target = $target; Gain = $level.Gain; LevelDb = $level.LevelDb })
                Add-Result barge-in ("""Kestrel"" for $target dBFS reaches the phone at $(if ($null -eq $level.LevelDb) { 'nothing' } else { "$($level.LevelDb) dBFS" }) with a gain of $([math]::Round($level.Gain, 2))" +
                    $(if ($level.InBand) { '' } else { '; not reached: this computer plays too quietly' }))
            }
        } finally {
            Invoke-Checked "rm -f $(Get-EvalFolder)/level.wav" | Out-Null
        }
        Start-Kestrel
        # Two thirds of the top lowers Kestrel's echo by about as much as the branch volume may (15 dB), so the row there
        # with the owner's level tests that branch directly.
        foreach ($index in @($volume.Max, [int][math]::Round($volume.Max * 2 / 3), [math]::Max(1, [int][math]::Round($volume.Max / 3)))) {
            Invoke-Checked "cmd media_session volume --stream 3 --set $index" | Out-Null
            foreach ($level in $levels) {
                $name = "volume $index of $($volume.Max), ""Kestrel"" for $($level.Target) dBFS"
                $echoes = [System.Collections.Generic.List[double]]::new()
                $done = 0
                $interrupted = 0
                for ($try = 1; $try -le $tries; $try++) {
                    try {
                        $result = Measure-BargeInTry -Gain $level.Gain
                    } catch {
                        if ($_.Exception.Message -eq 'The owner stopped the session.') { throw }
                        Add-Result barge-in "${name}, try ${try}: failed: $($_.Exception.Message)"
                        continue
                    }
                    # Without a reply there was nothing to interrupt, so the try does not count.
                    if ($null -eq $result.EchoDb) {
                        Add-Result barge-in "${name}, try ${try}: Kestrel did not begin its reply; counts: $($result.Rise)"
                        continue
                    }
                    $done++
                    $echoes.Add($result.EchoDb)
                    if ($result.Interrupted) { $interrupted++ }
                    Add-Result barge-in "${name}, try ${try}: Kestrel's own voice at $(if ($null -ne $result.EchoDb) { "$($result.EchoDb) dBFS" } else { 'nothing' }); $(if ($result.Interrupted) { 'interrupted' } else { 'not interrupted' }); counts: $($result.Rise)"
                }
                $sorted = @($echoes | Sort-Object)
                $echo = if ($sorted.Count -gt 0) { [math]::Round($sorted[[int][math]::Floor(($sorted.Count - 1) / 2)], 1) } else { $null }
                $rows.Add([pscustomobject]@{ Volume = $index; Max = $volume.Max; ClipDb = $level.LevelDb; EchoDb = $echo; Tries = $done; Interrupted = $interrupted })
                Add-Result barge-in "${name}: Kestrel's own voice at a median $(if ($null -ne $echo) { "$echo dBFS" } else { 'nothing' }); interrupted in $interrupted of $done tries"
            }
        }
        Invoke-Checked "cmd media_session volume --stream 3 --set $($volume.Max)" | Out-Null
        $tails = 0
        $tailTries = if ($DryRun) { 1 } else { 3 }
        for ($try = 1; $try -le $tailTries; $try++) {
            try {
                if (Measure-ReplyTail $try) { $tails++ }
            } catch {
                if ($_.Exception.Message -eq 'The owner stopped the session.') { throw }
                Add-Result barge-in "the reply's end, try ${try}: failed: $($_.Exception.Message)"
            }
        }
        Add-Result barge-in "a command started after $tails of $tailTries replies that nobody interrupted"
    } finally {
        Invoke-Hook voice-task @{ Clear = $true } | Out-Null
        Complete-Restore $volumeRestore
    }
    $decision = Get-BargeInDecision @($rows)
    Add-Result barge-in ("decision: branch=$($decision.Branch) reductionDb=$($decision.ReductionDb) nameDb=$($decision.NameDb) " +
        "echoDb=$($decision.EchoDb) workingEchoDb=$($decision.WorkingEchoDb) marginDb=$($decision.MarginDb)")
}

package dev.kestrel.voice.speak

import android.media.AudioDeviceInfo
import kotlin.math.pow

/**
 * How loud Kestrel speaks on the phone's own loudspeaker (design spec, section 8.4; plan 4E). There, a few centimetres
 * from the microphone, Kestrel's own voice masked the owner's "Kestrel" on the A71, so Kestrel speaks [REDUCTION_DB]
 * quieter than through earbuds or a headset, by the amount that plan 4E's measure on the A71 found.
 */
object SpeakerVolume {
    /** How much quieter Kestrel speaks on the phone's own loudspeaker, in dB. */
    const val REDUCTION_DB = 0f

    // The outputs at the owner's ears, from which Kestrel's voice does not reach the phone's microphone.
    private val PERSONAL = setOf(
        AudioDeviceInfo.TYPE_WIRED_HEADSET,
        AudioDeviceInfo.TYPE_WIRED_HEADPHONES,
        AudioDeviceInfo.TYPE_BLUETOOTH_A2DP,
        AudioDeviceInfo.TYPE_BLUETOOTH_SCO,
        AudioDeviceInfo.TYPE_BLE_HEADSET,
        AudioDeviceInfo.TYPE_USB_HEADSET,
        AudioDeviceInfo.TYPE_HEARING_AID,
    )

    /**
     * The gain of a reply's track when the phone's outputs have the types [outputs] (`AudioDeviceInfo`'s types, as
     * `AudioManager.getDevices(GET_DEVICES_OUTPUTS)` lists them): 1 when one of them is at the owner's ears, where Android
     * plays Kestrel's voice, and otherwise [reductionDb] below 1, because Kestrel then speaks on the phone's loudspeaker.
     */
    fun gain(outputs: List<Int>, reductionDb: Float = REDUCTION_DB): Float =
        if (outputs.any { it in PERSONAL }) 1f else 10f.pow(-reductionDb / 20f)
}
