# Kestrel v1 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Kestrel 1.0.0 as a signed APK on GitHub that the owner installs from the release page, and that downloads its own speech and OCR models after the owner taps Download in the setup checklist.

**Architecture:** The version becomes 1.0.0 (version code 100), and the convention plugin of `:app` signs the release build only when four environment variables name a key, so debug builds and CI's ordinary jobs stay as they are. A new workflow, `.github/workflows/release.yml`, runs CI's checks on a pushed tag `v*`, builds the release APK with the key from the repository's secrets, and publishes it with its SHA-256 hash. `:core:voice` gets `ModelDownloader`, which fetches the missing or damaged files of `models/manifest.json` through the network gateway's `Call.Factory`, resumes part files with an HTTP range, follows redirects one hop at a time so that the allowlist checks each host, unpacks sherpa-onnx's `.tar.bz2` archives with Apache Commons Compress and moves a file into place only after its SHA-256 hash matched. The manifest gets a list `downloadHosts`, which only requests marked with `ModelDownloadTag` may reach and which the build-time audit allows host by host. `:app` runs one download at a time in `AppGraph`'s scope and shows step 2 of the setup checklist with the voice (Kokoro first on a phone that can run it), a switch for mobile data, Download, the progress, Cancel and why a download stopped.

**Tech Stack:** Kotlin 2.4.21, kotlinx.coroutines 1.11.0, kotlinx.serialization 1.13.0, OkHttp 5.5.1 and mockwebserver3, `org.apache.commons:commons-compress` 1.28.0, Jetpack Compose (Material 3) and its test rule, AndroidX Test, JUnit 4, the Android Gradle plugin 9.5.1 (`ApplicationExtension.signingConfigs`), GitHub Actions with `gh`, the SDK's `keytool`, `apksigner` and `aapt2` (build-tools 36.0.0), PowerShell 7.3 and Windows PowerShell 5.1, Pester 6.2.0 and PSScriptAnalyzer 1.25.0.

## Global Constraints

- Package and application ID `dev.kestrel`; licence GPL-3.0-or-later. The only new dependency that ships in the app is `org.apache.commons:commons-compress:1.28.0` (Apache-2.0), an `implementation` of `:core:voice`, with the three libraries that it needs at run time, `commons-io:commons-io:2.20.0`, `org.apache.commons:commons-lang3:3.18.0` and `commons-codec:commons-codec:1.19.0`, all Apache-2.0; each gets an `allow` rule in `audit/rules.txt` and a row in `THIRD_PARTY_NOTICES.md`. Nothing else new ships.
- `minSdk 33`, `targetSdk 37`, `compileSdk 37`. Version 1.0.0 is `versionName "1.0.0"` and `versionCode 100`; each later release raises the code by at least one.
- No dependency-injection framework; `AppGraph` wires by hand. The download runs in `graph.scope`, whose failures go to `graph.errors`; a failure that Kestrel handles goes to `graph.report`/`reportFailure` by its classes only (design spec, section 13.5).
- All network traffic goes through `NetworkGateway`. The model download uses the gateway's `Call.Factory`, never `DownloadManager` (which the audit flags), never an `OkHttpClient` of its own; `audit/rules.txt` gets no new `allow-network-class` rule, only `allow-model-host` rules for the hosts in the manifest's `downloadHosts`. Only requests tagged `ModelDownloadTag` may reach those hosts, only over HTTPS, and the network log records them with the host, the sizes, the status and the fixed path `/model-download`.
- No request to any AI provider in any step of this plan: no `provider-check.ps1`, no `agent-live`, no sitting, no `task-check.ps1 -Live`. The only requests to the internet that this plan makes are the model downloads from the manifest's hosts (Task 5) and GitHub's (`gh`, the workflow; Task 7).
- Never log, print or put into a test's output the owner's words, screen text, a notification, a prompt, a reply, a vault value, a token, a key or a password. A `uiautomator` dump can hold the owner's notifications, so the steps only search it and never print it.
- Test only on kestrel-api37 (check `adb -s <serial> emu avd name` in the same command as each device command); never on the S23+ or the AVD `zoran`. This plan does not use the A71. The main session owns `.superpowers/sdd/emulator.lock` (process rule 9); subagents never create, wait for or delete it. Only one Gradle build at a time. Gradle only through `scripts\gradle.ps1`, stopped with `--stop` at the end of each task; device tests only through `scripts\connected-test.ps1` (with `-Pandroid.injected.androidTest.leaveApksInstalledAfterRun=true`); installs only through `scripts\install.ps1`.
- kestrel-api37 holds the owner's Google account and Kestrel's Copilot profile: no step uninstalls `dev.kestrel` or clears its data. A release build goes onto it only with `scripts\install.ps1 -Release`, which signs it with this computer's debug key and replaces the debug build with `adb install -r`, and the same step puts the debug build back.

Never commit a key, a keystore, its base64 text or a password; the key lives only in `%LOCALAPPDATA%\Kestrel\release-key` on this computer, in the repository's secrets and in the owner's own backup. ## Changes to the design that this plan makes

- The phone downloads its models itself (spec 8.10, D18, D20), after the owner taps Download in step 2 of the checklist, from the addresses in the manifest that comes with the app, through the gateway; the model hosts get the download requests from the phone's address and nothing else. "The phone itself never downloads a model" no longer holds.
- `models/manifest.json` gets `downloadHosts`: `github.com`, `release-assets.githubusercontent.com`, `objects.githubusercontent.com`, `raw.githubusercontent.com`, `huggingface.co`, `*.huggingface.co`, `*.hf.co` and `*.modelscope.cn`. The writer checked the redirects on 2026-11-23 with one-byte range requests: GitHub's release assets go to `release-assets.githubusercontent.com`, Hugging Face's large files to `us.aws.cdn.hf.co` and its small files to a relative `/api/resolve-cache/…` on `huggingface.co`, ModelScope's files to `cdn-lfs-cn-1.modelscope.cn`, and `raw.githubusercontent.com` answers without a redirect; every one of them answered a range request with 206.
- A new audit rule form `allow-model-host <host or *.domain> <justification>` and a new audit task `kestrelCheckModelHosts` (spec 13.2): each `downloadHosts` entry needs a rule, and each address in the manifest needs a host that the entries cover.
- The network log records a model download's requests with the path `/model-download` (spec 13.5), because a download server's path is a signed address that tells the owner nothing.
- Kokoro is the voice that step 2 chooses first on an arm64 phone that reports at least 5.5 GB of memory and has a CPU core of at least 2.8 GHz, and Piper elsewhere (spec 8.2): the A71's fastest cores run at 2.2 GHz, and there Kokoro needed 1.81 s per second of speech; the S23+'s fastest core runs at 3.36 GHz. The first-start measure of Kokoro's speed stays and still falls back to Piper. Piper is always downloaded.
- Step 2 of the checklist is "Download the speech models"; it is done when every model that is not optional is ready and, when the owner chose Kokoro for the download, Kokoro too. The voice that the owner chose becomes Kestrel's voice when the download ends.
- `ACCESS_NETWORK_STATE`, a permission that Android grants at install, so that Kestrel can tell Wi-Fi from mobile data.
- `scripts\install.ps1 -Release` builds the release APK signed with this computer's debug key and installs it over the debug build.
- The accessibility step says how to allow a restricted setting, because an app installed from a browser needs it.

```kotlin
package dev.kestrel.build

import java.io.File

/**
 * The key that signs Kestrel's release build, which four environment variables name (design spec, section 17). Its text
 * form leaves out both passwords.
 */
data class ReleaseSigning(val keystore: File, val storePassword: String, val keyAlias: String, val keyPassword: String) {
    override fun toString(): String = "ReleaseSigning(keystore=$keystore, keyAlias=$keyAlias)"

    companion object {
        const val KEYSTORE = "KESTREL_KEYSTORE"
        const val STORE_PASSWORD = "KESTREL_KEYSTORE_PASSWORD"
        const val KEY_ALIAS = "KESTREL_KEY_ALIAS"
        const val KEY_PASSWORD = "KESTREL_KEY_PASSWORD"

        /** The four variables, in the order in which the messages name them. */
        val VARIABLES = listOf(KEYSTORE, STORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD)

        /**
         * The key that the variables, which [read] reads, name; null when none of them is set, or each is empty, so that
         * the release build stays unsigned. Throws IllegalStateException, whose message names variables but never their
         * values, when only some are set or the keystore is no file.
         */
        fun from(read: (String) -> String?): ReleaseSigning? {
            val values = VARIABLES.associateWith { name -> read(name)?.takeIf { it.isNotEmpty() } }
            if (values.values.all { it == null }) return null
            val missing = VARIABLES.filter { values[it] == null }
            check(missing.isEmpty()) { "Set all four release-signing variables or none; missing: ${missing.joinToString()}" }
            val keystore = File(values.getValue(KEYSTORE)!!)
            check(keystore.isFile) { "$KEYSTORE names no file" }
            return ReleaseSigning(
                keystore,
                values.getValue(STORE_PASSWORD)!!,
                values.getValue(KEY_ALIAS)!!,
                values.getValue(KEY_PASSWORD)!!,
            )
        }
    }
}
```

```kotlin
package dev.kestrel.build

import com.android.build.api.dsl.ApplicationExtension
import dev.kestrel.build.audit.AuditPlugin
import org.gradle.api.Plugin
import org.gradle.api.Project
import org.gradle.kotlin.dsl.configure

/** For `:app`. It also applies the privacy audit, and it signs the release build when the environment names a key. */
class AndroidApplicationConventionPlugin : Plugin<Project> {
    override fun apply(target: Project) {
        target.applyKestrelApplicationDefaults()
        target.applyReleaseSigning()
        target.pluginManager.apply(AuditPlugin::class.java)
    }
}

/** Shared by `:app` and `:testapp`. Only `:app` is audited, because `:testapp` is never shipped. */
internal fun Project.applyKestrelApplicationDefaults() {
    pluginManager.apply("com.android.application")
    extensions.configure<ApplicationExtension> {
        applyKestrelAndroidDefaults()
        defaultConfig {
            targetSdk { version = release(KestrelSdk.TARGET) }
        }
    }
}

/**
 * Signs `:app`'s release build with the key that the variables of [ReleaseSigning] name (design spec, section 17): the
 * release workflow sets them from the repository's secrets, and `scripts\install.ps1 -Release` sets them to this
 * computer's debug key. Without them, as in CI's ordinary jobs, the release build stays unsigned.
 */
private fun Project.applyReleaseSigning() {
    val signing = ReleaseSigning.from { providers.environmentVariable(it).orNull } ?: return
    extensions.configure<ApplicationExtension> {
        val key = signingConfigs.maybeCreate("release")
        key.storeFile = signing.keystore
        key.storePassword = signing.storePassword
        key.keyAlias = signing.keyAlias
        key.keyPassword = signing.keyPassword
        buildTypes.getByName("release").signingConfig = key
    }
}
```

```powershell
# Returns the variables with which Gradle signs Kestrel's release build (design spec, section 17), set to this computer's
# debug key: the keystore that the Android Gradle plugin creates in the Android user folder, with its fixed alias and
# passwords. A release build signed with it installs over the debug build with adb install -r and keeps Kestrel's data.
# The release key never comes here.
function Get-DebugSigningEnvironment([string]$AndroidUserHome = $(if ($env:ANDROID_USER_HOME) { $env:ANDROID_USER_HOME } else { Join-Path $env:USERPROFILE '.android' })) {
    $keystore = Join-Path $AndroidUserHome 'debug.keystore'
    if (-not (Test-Path -LiteralPath $keystore -PathType Leaf)) {
        throw "No debug keystore at $keystore. Build the debug app once, for example with scripts\install.ps1."
    }
    [ordered]@{
        KESTREL_KEYSTORE          = $keystore
        KESTREL_KEYSTORE_PASSWORD = 'android'
        KESTREL_KEY_ALIAS         = 'androiddebugkey'
        KESTREL_KEY_PASSWORD      = 'android'
    }
}
```

```powershell
# Builds the debug APK and installs it with adb install -r (design spec, sections 13.6 and 15).
# The same Gradle call runs the privacy audit (section 13.2), so nothing is installed when the audit fails.
# Installing with adb avoids Android's restricted-settings block for accessibility services.
# -TestApp builds and installs the fixture app dev.kestrel.testapp instead, which the A71 sessions' automatic checks use
# (plan 4D); the session that installs it also uninstalls it.
# -Release builds the release APK instead, signed with this computer's debug key (Get-DebugSigningEnvironment), and
```

```kotlin
package dev.kestrel.build.audit

/**
 * A host from which the app may download its model files, or every host below a domain, written `*.domain`, with the
 * written justification of its `allow-model-host` rule in `audit/rules.txt` (release plan).
 */
data class ModelHostRule(val pattern: String, val justification: String)

/** The form of a model host: a host name, or `*.` and a domain. */
internal val MODEL_HOST_PATTERN = Regex("(\\*\\.)?[a-z0-9-]+(\\.[a-z0-9-]+)+")

/** Whether [host] is [pattern], or lies below the domain of a pattern `*.domain`, which the domain itself does not. */
fun hostMatches(pattern: String, host: String): Boolean =
    if (pattern.startsWith("*.")) host.length > pattern.length - 1 && host.endsWith(pattern.substring(1)) else host == pattern

/** Reads the hosts of `models/manifest.json` with regular expressions, because build-logic has no JSON library. */
internal object ManifestHosts {
    private val url = Regex("\"url\"\\s*:\\s*\"https://([^/\":]+)[/:]")
    private val list = Regex("\"downloadHosts\"\\s*:\\s*\\[([^\\]]*)]")
    private val item = Regex("\"([^\"]*)\"")

    /** The host of every HTTPS address of the manifest's files and archives. */
    fun urlHosts(manifest: String): Set<String> = url.findAll(manifest).map { it.groupValues[1].lowercase() }.toSortedSet()

    /** The manifest's `downloadHosts`, in their order. */
    fun downloadHosts(manifest: String): List<String> =
        list.find(manifest)?.groupValues?.get(1)?.let { inner -> item.findAll(inner).map { it.groupValues[1] }.toList() }.orEmpty()
}
```

```kotlin
package dev.kestrel.build.audit

import org.gradle.api.DefaultTask
import org.gradle.api.GradleException
import org.gradle.api.file.RegularFileProperty
import org.gradle.api.tasks.InputFile
import org.gradle.api.tasks.OutputFile
import org.gradle.api.tasks.PathSensitive
import org.gradle.api.tasks.PathSensitivity
import org.gradle.api.tasks.TaskAction

/**
 * Fails when `models/manifest.json` lists a download host that `audit/rules.txt` does not allow, or downloads from a host
 * that its `downloadHosts` do not cover (design spec, section 13.2; release plan).
 */
abstract class CheckModelHostsTask : DefaultTask() {
    @get:InputFile
    @get:PathSensitive(PathSensitivity.NONE)
    abstract val rulesFile: RegularFileProperty

    @get:InputFile
    @get:PathSensitive(PathSensitivity.NONE)
    abstract val manifestFile: RegularFileProperty

    @get:OutputFile
    abstract val report: RegularFileProperty

    @TaskAction
    fun check() {
        val manifest = manifestFile.get().asFile.readText()
        val problems = AuditRules.parse(rulesFile.get().asFile.readText()).checkModelHosts(manifest)
        val reportFile = report.get().asFile
        reportFile.parentFile.mkdirs()
        reportFile.writeText(
            ManifestHosts.downloadHosts(manifest).joinToString("\n", postfix = "\n") +
                if (problems.isEmpty()) "\nEvery model host is allowed.\n" else "\nProblems:\n" + problems.joinToString("\n", postfix = "\n"),
        )
        if (problems.isNotEmpty()) {
            throw GradleException("Model host audit failed (report: $reportFile):\n" + problems.joinToString("\n"))
        }
    }
}
```

```kotlin
                tar.write(content)
                tar.closeArchiveEntry()
            }
        }
```

```kotlin
package dev.kestrel.voice.models

import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.currentCoroutineContext
import kotlinx.coroutines.ensureActive
import kotlinx.coroutines.withContext
import okhttp3.Call
import okhttp3.HttpUrl.Companion.toHttpUrl
import okhttp3.Request
import okhttp3.Response
import org.apache.commons.compress.archivers.tar.TarArchiveInputStream
import org.apache.commons.compress.compressors.bzip2.BZip2CompressorInputStream
import java.io.File
import java.io.FileOutputStream
import java.io.IOException
import java.io.InputStream
import java.io.OutputStream
import java.nio.file.Files
import java.nio.file.StandardCopyOption

/** How far a download of the models is: [doneBytes] of the [totalBytes] that it fetches (release plan). */
data class DownloadProgress(val doneBytes: Long, val totalBytes: Long)

/**
 * Why a download of the models stopped (release plan). A `file` is a path of the manifest or an archive's id, which holds
 * nothing of the owner's, so the setup checklist names it.
 */
sealed interface DownloadFailure {
    /** The phone has no network. */
    data object NoNetwork : DownloadFailure

    /** The network counts its data, such as mobile data, and the owner allowed only networks that do not. */
    data object MeteredNetwork : DownloadFailure

    /** The download needs [neededBytes] of space, and the folder of the models has [freeBytes]. */
    data class NotEnoughSpace(val neededBytes: Long, val freeBytes: Long) : DownloadFailure

    /** A server answered with the HTTP [status], which is neither a success nor a redirect, or with too many redirects. */
    data class Server(val file: String, val status: Int) : DownloadFailure

    /** The network allowlist refused a host, such as a redirect to a host that the manifest does not name. */
    data class Refused(val file: String) : DownloadFailure

    /** The connection failed or broke. */
    data class Connection(val file: String) : DownloadFailure

    /** Kestrel could not write to the folder of the models. */
    data class Storage(val file: String) : DownloadFailure

    /** The file's size or SHA-256 hash differs from the manifest's, so Kestrel deleted it. */
    data class Damaged(val file: String) : DownloadFailure

    /** Any other failure, which the caller reports by its classes. */
    data object Unexpected : DownloadFailure
}

/** A download of the models that stopped for [failure]. Its message is only the failure's kind. */
class ModelDownloadException(val failure: DownloadFailure, cause: Throwable? = null) :
    IOException(failure::class.java.simpleName, cause)

/**
 * Downloads the model files that are missing or damaged under [files]' folder, from the addresses in [files]' manifest,
 * which comes with the app, through [calls], the network gateway's (design spec, section 8.10; release plan). Each file,
 * and each archive whose members Kestrel needs, first goes into a part file below the folder `.download`, which the next
 * download continues with an HTTP range. A file reaches its place only after its size and SHA-256 hash match the
 * manifest's; a part that does not match is deleted. Redirects are followed here, one request at a time, because the
 * gateway follows none, so that the allowlist checks each host. [decorate] marks each request for the allowlist and the
 * network log, and [refused] tells the allowlist's refusal from other failures.
 */
class ModelDownloader(
    private val files: ModelFiles,
    private val calls: Call.Factory,
    private val refused: (IOException) -> Boolean = { false },
    private val decorate: (Request.Builder) -> Request.Builder = { it },
) {
    /** The models that a download brings: every model that is not optional, and the Kokoro voice when [kokoro]. */
    fun wanted(kokoro: Boolean): List<Model> = files.manifest.models.filter { !it.optional || (kokoro && it.id == KOKORO_ID) }

    /**
     * Downloads every file of the [wanted] models that is missing or damaged. [gate] says before each file whether the
     * network may be used now, and [progress] hears the bytes fetched so far, also those of part files from earlier
     * downloads. Throws [ModelDownloadException]; a cancellation stops before the next 64 KB and keeps the part files.
     */
    suspend fun download(
        kokoro: Boolean,
        gate: () -> DownloadFailure? = { null },
        progress: (DownloadProgress) -> Unit = {},
    ): Unit = withContext(Dispatchers.IO) {
        val wantedIds = wanted(kokoro).map { it.id }.toSet()
        val needed = files.check().filter { it.model.id in wantedIds }.flatMap { it.missing + it.damaged }.toSet()
        val entries = files.manifest.models.flatMap { it.files }.filter { it.path in needed }
        val root = files.root
        val parts = File(root, DOWNLOADS)
        val direct = entries.filter { it.url != null }
            .map { Download(it.path, it.url!!, it.size, it.sha256, File(parts, it.path + PART)) }
        val members = entries.filter { it.url == null }.groupBy { it.archive!! }
        val archives = files.manifest.archives.associateBy { it.id }
        val packed = members.keys.map { id ->
            val archive = archives.getValue(id)
            Download(id, archive.url, archive.size, archive.sha256, File(parts, id + PART))
        }
        val total = (direct + packed).sumOf { it.size }
        var done = (direct + packed).sumOf { it.part.length().coerceAtMost(it.size) }
        val needs = total - done + members.values.sumOf { list -> list.sumOf { it.size } }
        val free = root.apply { mkdirs() }.usableSpace
        if (free < needs) throw ModelDownloadException(DownloadFailure.NotEnoughSpace(needs, free))
        progress(DownloadProgress(done, total))
        val count: (Long) -> Unit = { bytes ->
            done += bytes
            progress(DownloadProgress(done, total))
        }
        for (download in direct) {
            fetch(download, gate, count)
            place(download.part, files.file(download.name), download.name)
        }
        for (download in packed) {
            fetch(download, gate, count)
            unpack(download, members.getValue(download.name), parts)
        }
    }

    /** Brings [download]'s part file to its full size and checks its hash, or throws. */
    private suspend fun fetch(download: Download, gate: () -> DownloadFailure?, count: (Long) -> Unit) {
        val part = download.part
        part.parentFile?.mkdirs()
        if (part.length() > download.size) {
            count(-download.size)
            part.delete()
        }
        if (part.length() < download.size) {
            gate()?.let { throw ModelDownloadException(it) }
            val start = part.length()
            open(download, start).use { response ->
                // A server that ignores the range sends the whole file again.
                val append = start > 0 && response.code == 206
                if (start > 0 && !append) count(-start)
                val output = try {
                    FileOutputStream(part, append)
                } catch (e: IOException) {
                    throw ModelDownloadException(DownloadFailure.Storage(download.name), e)
                }
                // The output stream has truncated a part that starts over, so the part's length is where this body begins.
                try {
                    output.use { copy(response.body.byteStream(), it, download.name, download.size - part.length(), count) }
                } catch (e: ModelDownloadException) {
                    if (e.failure is DownloadFailure.Damaged) part.delete()
                    throw e
                }
            }
        }
        if (part.length() != download.size || sha256(part) != download.sha256) {
            part.delete()
            throw ModelDownloadException(DownloadFailure.Damaged(download.name))
        }
    }

    /** The response with the file's bytes from [start] on, after at most [MAX_REDIRECTS] redirects. */
    private fun open(download: Download, start: Long): Response {
        var url = download.url.toHttpUrl()
        var status = 0
        repeat(MAX_REDIRECTS + 1) {
            val builder = Request.Builder().url(url)
            if (start > 0) builder.header("Range", "bytes=$start-")
            val response = try {
                calls.newCall(decorate(builder).build()).execute()
            } catch (e: IOException) {
                val failure = if (refused(e)) DownloadFailure.Refused(download.name) else DownloadFailure.Connection(download.name)
                throw ModelDownloadException(failure, e)
            }
            status = response.code
            if (status == 200 || status == 206) return response
            val location = response.header("Location")?.let { response.request.url.resolve(it) }
            response.close()
            if (status !in REDIRECTS || location == null) throw ModelDownloadException(DownloadFailure.Server(download.name, status))
            url = location
        }
        throw ModelDownloadException(DownloadFailure.Server(download.name, status))
    }

    /** Copies at most [limit] bytes; a longer body is not the manifest's file, and it would fill the storage. */
    private suspend fun copy(input: InputStream, output: OutputStream, name: String, limit: Long, count: (Long) -> Unit) {
        val buffer = ByteArray(BUFFER_BYTES)
        var left = limit
        while (true) {
            currentCoroutineContext().ensureActive()
            val read = try {
                input.read(buffer)
            } catch (e: IOException) {
                throw ModelDownloadException(DownloadFailure.Connection(name), e)
            }
            if (read < 0) return
            if (read > left) throw ModelDownloadException(DownloadFailure.Damaged(name))
            left -= read
            try {
                output.write(buffer, 0, read)
            } catch (e: IOException) {
                throw ModelDownloadException(DownloadFailure.Storage(name), e)
            }
            count(read.toLong())
        }
    }

    /**
     * Unpacks [members] from [download]'s checked archive, each into a part file of its own, and moves each into place
     * after its hash matched. The archive's part file goes once every member is in place.
     */
    private suspend fun unpack(download: Download, members: List<ModelFile>, parts: File) {
        val byMember = members.associateBy { it.member!! }
        val placed = mutableSetOf<String>()
        try {
            TarArchiveInputStream(BZip2CompressorInputStream(download.part.inputStream().buffered(), true)).use { tar ->
                while (placed.size < byMember.size) {
                    currentCoroutineContext().ensureActive()
                    val entry = tar.nextEntry ?: break
                    val member = entry.name.removePrefix("./")
                    val file = byMember[member] ?: continue
                    val temporary = File(parts, file.path + PART)
                    temporary.parentFile?.mkdirs()
                    FileOutputStream(temporary).use { output -> tar.copyTo(output, BUFFER_BYTES) }
                    if (temporary.length() != file.size || sha256(temporary) != file.sha256) {
                        temporary.delete()
                        throw ModelDownloadException(DownloadFailure.Damaged(file.path))
                    }
                    place(temporary, files.file(file.path), file.path)
                    placed += member
                }
            }
        } catch (e: ModelDownloadException) {
            throw e
        } catch (e: IOException) {
            throw ModelDownloadException(DownloadFailure.Storage(download.name), e)
        }
        if (placed.size < byMember.size) throw ModelDownloadException(DownloadFailure.Damaged(download.name))
        download.part.delete()
    }

    private fun place(source: File, target: File, name: String) {
        try {
            target.parentFile?.mkdirs()
            Files.move(source.toPath(), target.toPath(), StandardCopyOption.REPLACE_EXISTING)
        } catch (e: IOException) {
            throw ModelDownloadException(DownloadFailure.Storage(name), e)
        }
    }

    /** One download: [name] is a file's path or an archive's id, and [part] holds its bytes until they are checked. */
    private class Download(val name: String, val url: String, val size: Long, val sha256: String, val part: File)

    companion object {
        /** The id of the Kokoro voice's model in models/manifest.json, which a download brings only when chosen. */
        const val KOKORO_ID = "tts-kokoro"

        private const val DOWNLOADS = ".download"
        private const val PART = ".part"
        private const val BUFFER_BYTES = 64 * 1024
        private const val MAX_REDIRECTS = 5
        private val REDIRECTS = setOf(301, 302, 303, 307, 308)
    }
}
```

```kotlin
package dev.kestrel.app.download

import android.app.ActivityManager
import android.content.Context
import android.net.ConnectivityManager
import android.net.NetworkCapabilities
import android.os.Build
import dev.kestrel.voice.VoiceChoice
import dev.kestrel.voice.models.DownloadFailure
import java.io.File
import java.io.IOException

/** The network that the phone uses now, for the model download (release plan). */
enum class NetworkKind { NONE, UNMETERED, METERED }

/**
 * Why a download of the models may not use a network of [kind] now, or null when it may: it needs a network, and one that
 * counts its data, such as mobile data, only with [mobileData] (release plan).
 */
fun downloadBlockedBy(kind: NetworkKind, mobileData: Boolean): DownloadFailure? = when {
    kind == NetworkKind.NONE -> DownloadFailure.NoNetwork
    kind == NetworkKind.METERED && !mobileData -> DownloadFailure.MeteredNetwork
    else -> null
}

/** The phone's network now, as Android rates it: Wi-Fi usually does not count its data, and mobile data does. */
fun networkKind(context: Context): NetworkKind {
    val connectivity = context.getSystemService(ConnectivityManager::class.java)
    val capabilities = connectivity.getNetworkCapabilities(connectivity.activeNetwork) ?: return NetworkKind.NONE
    if (!capabilities.hasCapability(NetworkCapabilities.NET_CAPABILITY_INTERNET)) return NetworkKind.NONE
    return if (capabilities.hasCapability(NetworkCapabilities.NET_CAPABILITY_NOT_METERED)) NetworkKind.UNMETERED else NetworkKind.METERED
}

/** What the voice's suggestion knows of the phone: its ABIs, its memory as Android reports it, and its fastest CPU core. */
data class Hardware(val abis: List<String>, val totalMemoryBytes: Long, val fastestCoreKhz: Long?)

/** Which voice step 2 of the setup checklist chooses first (design spec, section 8.2; release plan). */
object VoiceSuggestion {
    /** A phone with "6 GB" of memory reports about 5.5 to 5.8 GB. */
    const val MIN_MEMORY_BYTES = 5_500_000_000L

    /** 2.8 GHz: the A71's fastest cores run at 2.2 GHz, and the S23+'s fastest core at 3.36 GHz. */
    const val MIN_CORE_KHZ = 2_800_000L

    /**
     * Kokoro on an arm64 phone with at least [MIN_MEMORY_BYTES] of memory and a core of at least [MIN_CORE_KHZ], else
     * Piper. On the A71, Kokoro's fp32 model needed 1.81 s for each second of speech, and Kestrel's memory peaked at
     * 1037 MB with Kokoro. Kestrel still measures Kokoro when it first speaks with it, and Piper speaks where Kokoro is too
     * slow.
     */
    fun of(hardware: Hardware): VoiceChoice = when {
        ARM64 !in hardware.abis -> VoiceChoice.PIPER
        hardware.totalMemoryBytes < MIN_MEMORY_BYTES -> VoiceChoice.PIPER
        (hardware.fastestCoreKhz ?: 0L) < MIN_CORE_KHZ -> VoiceChoice.PIPER
        else -> VoiceChoice.KOKORO
    }

    private const val ARM64 = "arm64-v8a"
}

/**
 * Reads the phone's [Hardware]. The fastest core comes from the kernel's files in /sys; where Android does not let Kestrel
 * read them, it is null, and Piper comes first. It reads files, so call it off the main thread.
 */
fun readHardware(context: Context): Hardware {
    val memory = ActivityManager.MemoryInfo()
    context.getSystemService(ActivityManager::class.java).getMemoryInfo(memory)
    return Hardware(Build.SUPPORTED_ABIS.toList(), memory.totalMem, fastestCoreKhz())
}

private val CPU = Regex("cpu\\d+")

private fun fastestCoreKhz(): Long? = try {
    File("/sys/devices/system/cpu").listFiles { file -> CPU.matches(file.name) }.orEmpty()
        .mapNotNull { File(it, "cpufreq/cpuinfo_max_freq").takeIf(File::canRead)?.readText()?.trim()?.toLongOrNull() }
        .maxOrNull()
} catch (e: IOException) {
    null
} catch (e: SecurityException) {
    null
}
```

```kotlin
package dev.kestrel.app.download

import dev.kestrel.voice.VoiceChoice
import dev.kestrel.voice.models.DownloadFailure
import dev.kestrel.voice.models.DownloadProgress
import dev.kestrel.voice.models.ModelDownloadException
import kotlinx.coroutines.CancellationException
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Job
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.launch
import kotlinx.serialization.Serializable

/**
 * The voice and the network that the owner chose for the download of the models (release plan), stored encrypted like
 * every setting. A [voice] of null means the one that suits the phone ([VoiceSuggestion]).
 */
@Serializable
data class ModelDownloadSetting(val voice: VoiceChoice? = null, val mobileData: Boolean = false)

/** What step 2 of the checklist shows: the [voice] to download, the [suggested] one for this phone and [mobileData]. */
data class DownloadChoice(val voice: VoiceChoice, val suggested: VoiceChoice, val mobileData: Boolean)

/** Where the download of the models stands (release plan). */
sealed interface DownloadState {
    data object Idle : DownloadState

    data class Running(val doneBytes: Long, val totalBytes: Long) : DownloadState

    data object Done : DownloadState

    data object Cancelled : DownloadState

    data class Failed(val failure: DownloadFailure) : DownloadState
}

/**
 * Runs one download of the models at a time in [scope], which outlives the settings pages (release plan). [download]
 * fetches the files for Kokoro or not and for mobile data or not, and reports its progress; a failure other than
 * [ModelDownloadException] goes to [report], which logs it by its classes only (design spec, section 13.5).
 */
class ModelDownloads(
    private val scope: CoroutineScope,
    private val download: suspend (kokoro: Boolean, mobileData: Boolean, progress: (DownloadProgress) -> Unit) -> Unit,
    private val report: (String, Throwable) -> Unit,
) {
    private val states = MutableStateFlow<DownloadState>(DownloadState.Idle)

    /** Where the download stands; the end of the last download stays until the next one starts. */
    val state: StateFlow<DownloadState> = states.asStateFlow()

    private var job: Job? = null

    /**
     * Starts a download, unless one has not ended yet: a cancelled download may still write its last bytes. [onDone]
     * runs after a download that brought every file.
     */
    @Synchronized
    fun start(kokoro: Boolean, mobileData: Boolean, onDone: suspend () -> Unit = {}) {
        if (job?.isCompleted == false) return
        states.value = DownloadState.Running(0, 0)
        job = scope.launch {
            try {
                download(kokoro, mobileData) { states.value = DownloadState.Running(it.doneBytes, it.totalBytes) }
                onDone()
                states.value = DownloadState.Done
            } catch (e: CancellationException) {
                states.value = DownloadState.Cancelled
                throw e
            } catch (e: ModelDownloadException) {
                states.value = DownloadState.Failed(e.failure)
            } catch (e: Exception) {
                report("Downloading the models", e)
                states.value = DownloadState.Failed(DownloadFailure.Unexpected)
            }
        }
    }

    /** Stops the download; its part files stay for the next one. */
    @Synchronized
    fun cancel() {
        job?.cancel()
    }
}
```

```kotlin
internal fun ModelDownloadStep(data: SettingsData, needsAction: Boolean, onCheckModels: () -> Unit) {
    val stored by data.downloadChoice.collectAsState(initial = null)
    val download by data.modelDownload.collectAsState(initial = DownloadState.Idle)

    var written by remember { mutableStateOf<DownloadChoice?>(null) }
    val running = download is DownloadState.Running
    val view = LocalView.current
    DisposableEffect(running) {
        view.keepScreenOn = running
        onDispose { view.keepScreenOn = false }
    }
    LaunchedEffect(download) { if (download == DownloadState.Done) onCheckModels() }
```

```kotlin
            "ocr-ppocrv5-latin/ppocrv5_latin_dict.txt",
        )

            },
        )

    }

    private fun tarBz2(entries: Map<String, ByteArray>): ByteArray {
        val bytes = ByteArrayOutputStream()
        TarArchiveOutputStream(BZip2CompressorOutputStream(bytes)).use { tar ->
            for ((name, content) in entries) {
                tar.putArchiveEntry(TarArchiveEntry(name).apply { size = content.size.toLong() })
                tar.write(content)
                tar.closeArchiveEntry()
            }
        }
        return bytes.toByteArray()
    }

    private fun sha256(bytes: ByteArray): String =
        MessageDigest.getInstance("SHA-256").digest(bytes).joinToString("") { "%02x".format(it) }

        const val TAG = "KestrelModels"
    }
```

```yaml
name: Release

# Builds the signed release APK for a pushed tag v<version> and publishes it with its SHA-256 hash as a GitHub release
# (design spec, section 17; README, "Releasing"). A tag with a hyphen, such as v1.0.0-rc.1, makes a pre-release.
on:
  push:
    tags: ['v*']

permissions:
  contents: write

jobs:
  release:
    runs-on: ubuntu-24.04
    timeout-minutes: 60
    steps:
      # The first eight steps are those of ci.yml's job build, so that a release passes the same checks.
      - uses: actions/checkout@v7
        with:
          # The job's write token stays out of .git/config, where the build's plugins could read it.
          persist-credentials: false
      - uses: actions/setup-java@v6
        with:
          distribution: temurin
          java-version: '21'
      - uses: gradle/actions/setup-gradle@v6
        with:
          # As in ci.yml: the next step saves only the downloaded dependencies and the Gradle distributions.
          cache-provider: external
      - name: Restore Gradle's downloads
        # As in ci.yml, with the same key, so that a release reuses CI's downloads.
        uses: actions/cache@v6
        with:
          path: |
            ~/.gradle/caches/modules-2
            ~/.gradle/wrapper/dists
          key: gradle-${{ runner.os }}-${{ hashFiles('**/*.gradle.kts', 'gradle/libs.versions.toml', 'gradle/verification-metadata.xml', 'gradle/wrapper/gradle-wrapper.properties', 'gradle/gradle-daemon-jvm.properties') }}
          restore-keys: |
            gradle-${{ runner.os }}-
      - name: Install Android SDK packages
        run: |
          yes | "$ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager" --licenses > /dev/null
          "$ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager" "platforms;android-37.0" "build-tools;36.0.0" > /dev/null
      - name: Resolve the build's plugins
        # As in ci.yml: Maven Central sometimes answers GitHub's runners HTTP 429, so the build is configured up to five
        # times.
        run: |
          refresh=""
          wait=30
          for attempt in 1 2 3 4 5; do
            if ./gradlew help --info --console=plain $refresh > "$RUNNER_TEMP/resolve.log" 2>&1; then
              exit 0
            fi
            echo "Attempt $attempt to configure the build failed:"
            grep -iE "HTTP [0-9]{3}|could not|status code|not found|timed out|refused|reset" "$RUNNER_TEMP/resolve.log" | head -n 40 || true
            refresh="--refresh-dependencies"
            if [ "$attempt" -lt 5 ]; then sleep "$wait"; wait=$((wait * 2)); fi
          done
          tail -n 80 "$RUNNER_TEMP/resolve.log"
          exit 1
      - name: Unit tests, lint and the privacy audit
        run: ./gradlew :build-logic:convention:check check kestrelAudit --console=plain
      - name: Check that generated files are committed
        run: |
          git status --porcelain
          test -z "$(git status --porcelain)"
      - name: Decode the release key
        env:
          KEYSTORE_BASE64: ${{ secrets.KESTREL_KEYSTORE_BASE64 }}
        run: |
          if [ -z "$KEYSTORE_BASE64" ]; then
            echo "The repository has no secret KESTREL_KEYSTORE_BASE64."
            exit 1
          fi
          printf '%s' "$KEYSTORE_BASE64" | base64 --decode > "$RUNNER_TEMP/kestrel-release.p12"
      - name: Build the signed release APK
        env:
          KESTREL_KEYSTORE: ${{ runner.temp }}/kestrel-release.p12
          KESTREL_KEYSTORE_PASSWORD: ${{ secrets.KESTREL_KEYSTORE_PASSWORD }}
          KESTREL_KEY_ALIAS: ${{ secrets.KESTREL_KEY_ALIAS }}
          KESTREL_KEY_PASSWORD: ${{ secrets.KESTREL_KEY_PASSWORD }}
        run: ./gradlew :app:assembleRelease --console=plain
      - name: Check the APK's version and signature
        run: |
          tools="$ANDROID_HOME/build-tools/36.0.0"
          apk=app/build/outputs/apk/release/app-release.apk
          version="${GITHUB_REF_NAME#v}"
          badging="$("$tools/aapt2" dump badging "$apk" | head -n 1)"
          echo "$badging"
          case "$badging" in
            *"versionName='${version%%-*}'"*) ;;
            *) echo "The APK's versionName differs from ${version%%-*}, the version of the tag $GITHUB_REF_NAME."; exit 1 ;;
          esac
          certificates="$("$tools/apksigner" verify --print-certs "$apk")"
          echo "$certificates"
          if printf '%s\n' "$certificates" | grep -q 'CN=Android Debug'; then
            echo "The APK carries a debug key."
            exit 1
          fi
      - name: Write the APK and its SHA-256 hash
        run: |
          version="${GITHUB_REF_NAME#v}"
          mkdir -p "$RUNNER_TEMP/release"
          cp app/build/outputs/apk/release/app-release.apk "$RUNNER_TEMP/release/kestrel-$version.apk"
          cd "$RUNNER_TEMP/release"
          sha256sum "kestrel-$version.apk" > "kestrel-$version.apk.sha256"
          cat "kestrel-$version.apk.sha256"
      - name: Create the GitHub release
        env:
          GH_TOKEN: ${{ github.token }}
        run: |
          version="${GITHUB_REF_NAME#v}"
          cd "$RUNNER_TEMP/release"
          prerelease=()
          case "$GITHUB_REF_NAME" in *-*) prerelease=(--prerelease) ;; esac
          gh release create "$GITHUB_REF_NAME" "kestrel-$version.apk" "kestrel-$version.apk.sha256" \
            --repo "$GITHUB_REPOSITORY" --verify-tag --title "Kestrel $version" "${prerelease[@]}" \
            --notes "Kestrel $version, signed with Kestrel's release key. Compare the SHA-256 hash of kestrel-$version.apk with kestrel-$version.apk.sha256 before you install it. How to install it and set it up: https://github.com/$GITHUB_REPOSITORY#installing-from-a-release"
      - name: Delete the release key
        if: always()
        run: rm -f "$RUNNER_TEMP/kestrel-release.p12"
```

### Task 7: The release key, the secrets and the tags (the controller's own)

**Files:**
- None in the repository. The key goes to `%LOCALAPPDATA%\Kestrel\release-key`, the secrets to the repository's settings on GitHub, and the tags to `origin`.

**Interfaces:**
- Consumes: Task 6's workflow and its four secrets' names; Task 1's `versionName "1.0.0"`; `gh` signed in as the owner's account, with the right to set the secrets of `ak800i/kestrel`.
- Produces: the release key, the four secrets, the pre-release `v1.0.0-rc.1` (deleted after its check) and the release `v1.0.0` with `kestrel-1.0.0.apk` and `kestrel-1.0.0.apk.sha256`.

The owner's decision of 2026-11-23: the controller creates the key with keytool and sets the secrets with `gh secret set`; no agent touches the S23+, and the owner installs the release himself. The key is a PKCS12 keystore, whose store and key passwords are the same, as PKCS12 requires; the password is random and is kept only protected for the owner's Windows account (DPAPI) next to the keystore. A key that exists already is never replaced, because every later release must carry the same key. The pre-release checks the workflow end to end before the real tag; its APK carries the real key, so it never goes onto a test device. The tags go onto `main` after the controller has merged tracks A and B there.

- [ ] **Step 1: Create the release key**

Run this block in PowerShell 7 from the repository's root:

```powershell
$ErrorActionPreference = 'Stop'
. scripts\lib\Kestrel.ps1; Use-KestrelToolchain
$folder = Join-Path $env:LOCALAPPDATA 'Kestrel\release-key'
$keystore = Join-Path $folder 'kestrel-release.p12'
if (Test-Path -LiteralPath $keystore) { throw "A release key exists at $keystore already; it is never replaced." }
New-Item -ItemType Directory -Force -Path $folder | Out-Null
$bytes = New-Object byte[] 24
[Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($bytes)
$env:KESTREL_RELEASE_PASSWORD = [Convert]::ToBase64String($bytes) -replace '[+/=]', 'x'
try {
    & "$env:JAVA_HOME\bin\keytool.exe" -genkeypair -keystore $keystore -storetype PKCS12 -alias kestrel -keyalg RSA -keysize 4096 -validity 10000 -dname 'CN=Kestrel, O=ak800i' -storepass:env KESTREL_RELEASE_PASSWORD -keypass:env KESTREL_RELEASE_PASSWORD
    if ($LASTEXITCODE -ne 0) { throw 'keytool failed' }
    ConvertTo-SecureString $env:KESTREL_RELEASE_PASSWORD -AsPlainText -Force | ConvertFrom-SecureString | Set-Content -LiteralPath (Join-Path $folder 'password.dpapi')
} finally {
    Remove-Item env:KESTREL_RELEASE_PASSWORD
}
Get-ChildItem -LiteralPath $folder | Select-Object Name, Length
```

Expected: keytool creates the key without printing a password; the folder holds `kestrel-release.p12` (about 4 to 5 KB) and `password.dpapi`. Tell the owner in the controller's report that he must copy the folder and the password, which `$p = Get-Content (Join-Path $env:LOCALAPPDATA 'Kestrel\release-key\password.dpapi') | ConvertTo-SecureString; [Net.NetworkCredential]::new('', $p).Password` shows in his own window, into his own backup, such as his password manager, because without them no later release installs over this one.
