# Notes for agents

- The design is in [docs/superpowers/specs/2026-11-12-kestrel-design.md](docs/superpowers/specs/2026-11-12-kestrel-design.md), and the plans are in [docs/superpowers/plans/](docs/superpowers/plans/). The progress of the plan that is being carried out is in `.superpowers/sdd/progress.md`, a local file that is not in git.
- Test only on the `kestrel-api37` emulator (`emulator-5554`). An emulator's serial depends on the order in which emulators start, and `zoran` has had `emulator-5554` too, so use the serial that `scripts\start-emulator.ps1` prints, and check with `adb -s <serial> emu avd name` that it is `kestrel-api37` before you run anything on it. Never use the AVD `zoran` or the Galaxy S23+. Automated checks and investigations may use the Galaxy A71 (`R58N66RVD7Z`) while it is on USB, without the owner, within these limits: no call, no message, no change to his accounts, every setting put back afterwards, and no words that Kestrel heard in any result. Anything that needs the owner's hands waits for a plan step that names it.
- Run Gradle through `scripts\gradle.ps1`, and stop it with `scripts\gradle.ps1 --stop` when you are done.
- Run device tests only through `scripts\connected-test.ps1`, `scripts\voice-test.ps1`, `scripts\command-test.ps1` (the instant commands, on the emulator only), `scripts\provider-check.ps1` (the providers' live cases, which call Copilot: only in the owner's session, or against the stand-in of `scripts\hook.ps1 provider-standin`) `scripts\listen-check.ps1` or `scripts\task-check.ps1` (the agent's tasks: with `-Script` on the emulator, and with the owner's Copilot only inside a sitting of `scripts\a71-agent.ps1`), as each plan says, and install only through `scripts\install.ps1`, which installs the test app of the A71 sessions with `scripts\install.ps1 -TestApp`.
- `Get-Adb` and the other helpers exist only after `. scripts\lib\Kestrel.ps1; Use-KestrelToolchain`, so run that in the same command that uses them.
- After you change a script, run `scripts\test-scripts.ps1`.
