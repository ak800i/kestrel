# Notes for agents

- The design is in [docs/superpowers/specs/2026-11-12-kestrel-design.md](docs/superpowers/specs/2026-11-12-kestrel-design.md), and the plans are in [docs/superpowers/plans/](docs/superpowers/plans/). The progress of the plan that is being carried out is in `.superpowers/sdd/progress.md`, a local file that is not in git.
- The owner's hard rule for every plan, task and fix: no workarounds and no smallest-change fixes. Do things properly and cleanly: clean code, good architecture and modularity are a must, even when that means a big effort or a large change.
- Test only on the `kestrel-api37` emulator (`emulator-5554`). An emulator's serial depends on the order in which emulators start, and `zoran` has had `emulator-5554` too, so use the serial that `scripts\start-emulator.ps1` prints, and check with `adb -s <serial> emu avd name` that it is `kestrel-api37` before you run anything on it. Never use the AVD `zoran` or the Galaxy S23+. Automated checks and investigations may use the Galaxy A71 (`R58N66RVD7Z`) while it is on USB, without the owner, within these limits: no call; no message, except the task suite's own messages to his Telegram's Saved Messages and its e-mails to himself; no change to his accounts, except the suite's calendar events and contacts in his secondary Google account, each removed after its run; every setting put back afterwards; and no words that Kestrel heard in any result. Anything that needs the owner's hands waits for a plan step that names it.
- Run Gradle through `scripts\gradle.ps1`, and stop it with `scripts\gradle.ps1 --stop` when you are done. It refuses every task that installs, uninstalls or runs tests on a device, also by an abbreviated name.
- Run device tests only through `scripts\connected-test.ps1`, `scripts\voice-test.ps1`, `scripts\command-test.ps1` (the instant commands, on the emulator only), `scripts\provider-check.ps1` (the providers' live cases, which call Copilot: only in the owner's session, or against the stand-in of `scripts\hook.ps1 provider-standin`) `scripts\listen-check.ps1` or `scripts\eval.ps1` (`:tools:eval`: the agent's task suite, the injection fixtures, their rehearsals and the egress check; the scripted model by default; with `--live`, the owner's default profile in test mode, on kestrel-api37 and the A71 only, never on the S23+, with no ceiling on AI Credits), as each plan says, and install only through `scripts\install.ps1`, which installs the test app of the A71 sessions with `scripts\install.ps1 -TestApp`. PCAPdroid, which the egress check needs on both test devices, is the one app that a script installs otherwise, through `scripts\eval.ps1 egress-setup`; it stays installed, with its API key in the git-ignored `eval\local\`. Before every live series, `:tools:eval` grants Kestrel the evaluation's permission set on the device (READ_CALENDAR, READ_CONTACTS, WRITE_CONTACTS, READ_SMS, READ_CALL_LOG, READ_MEDIA_IMAGES and READ_MEDIA_VIDEO), and by the owner's decision of 2026-11-24 they stay granted on both test devices: no restore takes them back. Location, phone state and call answering are not in the set and stay as the owner left them.
- `Get-Adb` and the other helpers exist only after `. scripts\lib\Kestrel.ps1; Use-KestrelToolchain`, so run that in the same command that uses them.
- `scripts\connected-test.ps1` never lets Gradle uninstall Kestrel or clear its data: it passes the Gradle properties for that itself (`$KestrelDataProperties` in `scripts\lib\Kestrel.ps1`), refuses every argument that sets them otherwise and every task but a connected test, and ends with exit code 1 when Kestrel was uninstalled or installed again during the run. Never run connected tests in another way.
- `scripts\a71-agent.ps1` runs the two sittings of the agent (sub-project 5) on the A71 and kestrel-api37. Its sitting 2, which the owner starts, calls Copilot through `scripts\eval.ps1 run --live`, but live runs no longer need a sitting: `scripts\eval.ps1 --live` runs them by itself; `-DryRun` runs either sitting on kestrel-api37 with the scripted model. Each sitting turns the live session (`scripts\hook.ps1 agent-live`) off at its start, and sitting 2 turns it off again however it ends. The owner wants to be needed as little as possible: before a sitting asks him for anything, it checks whether that is already done. Sitting 1 needs his hands for about 2 minutes (one real touch of the A71's screen), plus 0 to 6 minutes for missing apps from Play, about 4 for Telegram's sign-in on the A71 and about 2 when the A71's Waze has no Home; sitting 2 needs nothing when both devices have a Copilot profile as their default, else about 3 minutes for each device that lacks one. Telegram runs only on the A71 (it is not signed in on kestrel-api37, and must not be), WhatsApp is skipped on both devices, and Waze is skipped on kestrel-api37, where it does not work.
- kestrel-api37 holds the owner's own Google account and Kestrel's Copilot profile. No script or agent may sign them in, remove them or clear them there, in any step, a stop or a dry run; before and after a run on it, check that `dumpsys account` still counts the same Google accounts and that `scripts\hook.ps1 -Serial <serial> -Command provider-standin` still answers `profile=copilot`.
- After you change a script, run `scripts\test-scripts.ps1`.
